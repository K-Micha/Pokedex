# Pokédex

A responsive Pokédex web application built by Michael Kühn. It retrieves Pokémon data from the PokéAPI and provides search, detail views and evolution information.

## Live Demo

[Open Pokédex](https://k-micha.github.io/Pokedex/)

## Features

* Search Pokémon by name or ID
* Display Pokémon details and statistics
* Show up to three evolution stages
* Navigate between Pokémon
* Close detail views with the Escape key or overlay
* Responsive design for desktop, tablet and mobile devices

## Technologies

* HTML5
* CSS3
* JavaScript
* REST API
* PokéAPI

## Data Source

Pokémon data is provided by the [PokéAPI](https://pokeapi.co/).
